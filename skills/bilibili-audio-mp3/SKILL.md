# Bilibili 音訊轉 MP3

使用者提供 Bilibili 影片連結並要求 MP3 音訊時，完成擷取與轉檔，最後回報檔案路徑、位元率與檔案大小。

## 流程

1. 確認網址是 Bilibili 影片連結。若使用者提供多個網址，逐一處理並讓輸出檔名彼此不同。
2. 檢查環境是否有 `yt-dlp` 與 `ffmpeg`。使用已安裝的工具；未經使用者同意，不安裝軟體或更改系統設定。缺少工具時先說明缺項，再詢問是否需要安裝。
3. 使用 `yt-dlp` 取得最佳可用音訊串流，再透過 FFmpeg 擷取為 MP3。若有純音訊格式，不要下載影片串流。
4. 以影片標題命名，清理本機檔案系統不接受或不安全的字元，且避免覆寫既有檔案。可行時存至目前工作區的 `outputs/`；否則使用使用者可寫入的任務輸出目錄。
5. 選擇實用的 MP3 位元率：明確的口語內容用 128 kbps；音樂或內容類型不明時用 192 kbps。若使用者指定位元率或大小目標，在技術上合理時依其要求處理，並說明取捨。
6. 驗證輸出檔存在、非空，且可辨識為 MP3。回報檔案路徑、位元率與大小。

## 存取限制

- 只處理使用者有權存取及轉換的內容。
- 不繞過 DRM、付費牆、存取控制或平台限制，也不嘗試破解反機器人防護。
- 若影片需要登入，停止並說明使用者可提供已授權的本機登入狀態或可存取的副本。不可要求使用者在對話中傳送密碼、session token 或私人 cookies。
- 若平台或擷取工具阻擋請求，清楚回報失敗，不改用可疑的下載服務。
