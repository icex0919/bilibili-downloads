# Bilibili Downloads Skills

Two Codex skills for authorized Bilibili media downloads:

- `skills/bilibili-audio-mp3`: extract audio and save it as a practical-size MP3.
- `skills/bilibili-video-1080p`: download the best available video at up to 1080p as MP4.

Both skills use `yt-dlp` and FFmpeg when available and preserve platform access restrictions.
